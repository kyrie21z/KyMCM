# Markdown Format

- Save Markdown as UTF-8.
- Write inline mathematics as `$...$` and display mathematics as `$$...$$`.
- Do not place bare LaTeX commands in prose.
- Keep tables rectangular, with one header row and a delimiter row.
- Use workspace-relative Markdown links and evidence paths; never use absolute paths or `..` traversal.
- Standard Markdown is authoritative; Obsidian-only syntax is never required.
