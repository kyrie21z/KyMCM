# Contract Review Checklist

## Problem Contract

- Problem interpretation and goals are complete.
- Subproblem inputs and outputs are explicit.
- Shared symbols and data sources are defined.
- Ambiguities and user decisions are listed.
- Dependency graph is acyclic; topological order is a stable suggestion, not a strict question-number gate.
- Review acknowledges that any approved new version conservatively invalidates existing work.

## Solution Contract Qi

- Required predecessor outputs are identified.
- Assumptions, variables, objectives, and constraints are precise.
- Model and algorithm are selected.
- Input/output interfaces are testable.
- Validation criteria are executable and require evidence.
- Current Problem Contract and direct dependency Solution versions are available for the approval snapshot.
- Review acknowledges that a replacement invalidates this problem and DAG successors.
- User decisions are resolved or explicitly blocked.

## Final Paper Checkpoint

- Formulas match approved Solution Contracts.
- Results match validated outputs.
- Figures, conclusions, citations, and formatting are complete.
- Every problem and global validation hash and evidence file has been revalidated.
